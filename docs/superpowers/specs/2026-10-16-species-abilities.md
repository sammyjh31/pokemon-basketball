# Species abilities across basketball modes

Use each species' first normal PokéAPI ability, pinned in a separate catalog. Translate canonical names into explicitly described basketball mechanics. The game is not a Pokémon battle simulator: effects are modest, conditional shot-probability adjustments for the shooter, creator, or primary defender. No hidden random activation rolls. Ability effects complement types, body matchups, court actions and fatigue.

New solo, local and arcade games use ability rules version 1. New franchise seasons adopt them; historical inputs without the flag retain the original behavior. Local leagues retain their explicit ability toggle. New abilities replace the old type-derived signature layer when enabled rather than stacking both layers.

Record offensive, support and defensive activations only when the effect is applied to a shot contest. Counts measure involvement, not points caused or successful baskets. Show ability names/descriptions in scouting, activation breakdowns in game boxes and season/playoff stats, and preserve them in historical boxes and career totals. Official arcade counts represent actual playable events and are not multiplied by the score normalization factor.

Coaches value roster ability/tactic synergy, consider opponents' ability strengths, use ability fit in rotations, and incorporate ability-linked skills into automatic training with a visible explanation. These decisions are guarded by the version flag to preserve historical replay.

Validate deterministic replay, disabled/legacy behavior, no-insights parity, mode defaults, save round trips, aggregation and official arcade conversion. Review and push coherent commits to origin/main.
