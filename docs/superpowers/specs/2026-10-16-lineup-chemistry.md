# On-court team chemistry and ability synergies

Build chemistry that depends on the actual five Pokémon playing together, in every simulated and playable game. Coaches should select complementary units and schemes automatically. Eight-player rosters, manual minutes/closers, fouls, fatigue, unique species and existing historical saves remain supported.

Use a pure `lineupChemistry.ts` model. Basketball chemistry measures creation, spacing, interior presence, defensive coverage and composure, with existing local familiarity as a small input. It gives bounded passing, screen timing and defensive coordination modifiers. Ability combinations are additional, named basketball adaptations between distinct active players: creator/finisher, screen/shooter, perimeter pressure/anchor, rebound/outlet, tempo/endurance, support partnerships and the specific Plus/Minus pair. Benefits target the participating players, not benched donors, and duplicate providers use strongest-per-effect rather than unlimited stacking. Ability-off leagues retain basketball chemistry but lose ability combinations. Do not add new RNG draws or rewrite stored ratings.

The model returns a score, bounded team-value contribution, strengths/weaknesses, named player links and per-player multipliers for passing, movement, screens, navigation, rebounds, defense and energy drain. Recompute after substitutions/foul replacements and scheme changes; snapshot/cache by active IDs and scheme only within a game. Remove the old generic local chemistry bonus for new chemistry-version games so it is not counted twice. Keep its exact legacy behavior for old games.

Coaches evaluate complete five-player units with the shared model while honoring role fit, fatigue, target minutes, closers and fouls. Bounded lineup search must remain fast enough for full-season simulation. Game plans and shared roster evaluation consider combinations rather than independently summed individual abilities. Training can benefit through existing shared evaluation where applicable. CPU arcade substitutions evaluate the actual incoming/outgoing five, and manual substitutions immediately update effects.

Show projected chemistry and named combinations in coaching/roster views, and actual five-player chemistry in existing game/season lineup reports. Reports describe lineup opportunities and modifiers, not invented synergy points or shot activations. Existing individual physical counters keep their original attribution; partner benefits are described in lineup reports.

Add `chemistryVersion: 1` independently from existing ability/physical/evaluation flags. New solo and local games opt in; existing franchises adopt only at the next season boundary. Persist and validate the flag through archives, local careers and official playable games. Missing flags preserve current ec43701 results exactly.

Validate distinct-player/no-bench/dedup/permutation invariants, boundedness, actual simulation and arcade outcomes, substitution refresh, disabled abilities, coaching choices and constraints, legacy hashes, version transitions, full franchise save/restore and responsive UI. No new dependencies or changes to user saves.
