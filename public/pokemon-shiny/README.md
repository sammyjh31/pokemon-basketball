# Shiny Pokémon pixel sprites

Front-facing shiny sprites for National Pokédex IDs **1–1025**, stored as `{id}.png`.

## Source and provenance

Downloaded unchanged from the primary [PokéAPI sprites repository](https://github.com/PokeAPI/sprites), pinned to commit [`97a7832d307311c0e1c6ea9035308bf80cc94f81`](https://github.com/PokeAPI/sprites/tree/97a7832d307311c0e1c6ea9035308bf80cc94f81/sprites/pokemon/shiny).

Source URL pattern:

```text
https://raw.githubusercontent.com/PokeAPI/sprites/97a7832d307311c0e1c6ea9035308bf80cc94f81/sprites/pokemon/shiny/{id}.png
```

The upstream [README](https://github.com/PokeAPI/sprites/blob/97a7832d307311c0e1c6ea9035308bf80cc94f81/README.md) identifies this collection as the default Pokémon PNG sprites with shiny variants. It credits the Smogon community for custom Black & White style sprites for later generations. The upstream [contribution guide](https://github.com/PokeAPI/sprites/blob/97a7832d307311c0e1c6ea9035308bf80cc94f81/CONTRIBUTING_SPRITES.md) explains that official Generation V pixel sprites do not exist for newer Pokémon, so community-made sprites complete the National Dex in that style. These are the source collection's shiny palettes; no CSS recoloring or generated artwork was used.

## Coverage and validation

- Included: all 1,025 IDs from 1 through 1025; no missing or substituted assets.
- Every image is a 96 × 96 PNG.
- PNG payloads total 1,051,986 bytes (about 1.00 MiB).
- Verified file signatures, all chunk CRCs, image headers, successful raster decompression, raster byte lengths, scanline filters, and complete ID coverage.

Pokémon and related character artwork remain the property of their respective rights holders. Refer to the upstream project for its attribution and usage information.
