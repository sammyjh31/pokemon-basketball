# Persistent teammate familiarity

Track actual pairwise shared court minutes, grow chemistry through regular-season, playoff and official playable games, and preserve those relationships across franchise years. Only shared active-five time counts; bench minutes, simulations for previews/replays and duplicate submissions never independently earn familiarity. Growth affects subsequent fixtures; each game's pregame relationships are frozen for exact replay. User and CPU teams use identical rules.

New `chemistryGrowthVersion: 1` accompanies chemistryVersion1. LeagueTeam has optional `chemistryBonds: Record<string,number>` of canonical ascending `id:id` pair keys and effective shared minutes (two decimals, cap6000). Preserve historical absent versions exactly; new games opt in and existing franchises adopt at next season with empty memory. Never fabricate prior shared time. Each offseason retains90% of minutes exactly once at next-season transition. Relationship memory survives roster changes; a moved pair carries its connection, other newcomers have zero history with unfamiliar teammates. Clubs retain past pairs for potential reunions. Merge pair memories by maximum across clubs on transactions, never sum copied histories. Validate catalog IDs, canonical keys, finite bounds, consistent flags and a bounded bank.

Lineup continuity averages bond strength `minutes/(minutes+600)` across ten actual pairs. It replaces the old coarse local annual familiarity bonus and adds up to6 cohesion points; existing ability partnership strengths get up to25% extra effectiveness from that specific pair, within existing modifier caps. Coaches use the same combined lineup value, with actual pair strengths in game plans, rotation search, training and market decisions. Rookies remain recruitable on skill/upside; unfamiliarity is a modest lost bonus, not a permanent penalty.

`LeagueMatch.chemistryMinutes` holds actual shared minutes by home/away, even when detailed insights are disabled. Simulation accumulates from actual active-five elapsed time, arcade from actual clock time and official conversion scales minutes12x like player minutes. Only official completed fixtures advance relationship state. Season and playoff builders keep initial teams frozen, store compact pregame fixture snapshots as 28 numeric minutes per side in sorted roster-pair order, and publish final bond banks separately. Archive reconstruction rebuilds those snapshots sequentially; opening a box score must use that fixture snapshot. Playoffs start with regular-season final history. Offseason teams inherit final playoff/regular history before trades, rookie replacement and free agency.

Show familiarity and shared minutes for the projected active five and actual lineup details; explain experienced connections and new pairings. Current coaching previews must use the latest completed games. Keep old skill-cohesion reports compatible. No new dependencies, RNG draws, injuries or morale simulation, no user-save changes during validation.
