# Playoffs implementation plan

Goal: Add a complete, resumable 16-team postseason to existing league seasons.
Spec: ../specs/2026-10-15-playoffs.md
Architecture: additive playoff model and deterministic replay; existing regular-season engine unchanged. Separate presentation and persistence/integration domains consume explicit playoff interfaces.
Stack: React, TypeScript, Vite, Vitest; no new dependencies.

## Constraints and review focus
- Preserve model-3 regular seasons and all older saves without changing their outcomes.
- Fixed 16-team seeding, 15 best-of-seven series, 2–2–1–1–1 home court; no reseeding.
- Postseason statistics and Finals MVP never use regular-season production or increment challenge counters.
- Partial progression resumes exactly after reload; malformed playoff data must not discard a valid regular season.
- No duplicate/stale async application, hidden result spoilers, inaccessible box-score dialogs or mobile page overflow.

- [x] Persistence/state: optional `Run.playoffs`, guarded `APPLY_PLAYOFFS`, hook async callback, App props and reset locking. Bound replay validation at 105 games. Test legacy saves, partial/full restore, corrupted extension recovery, stale actions and counters.
- [x] Integration: whole suite/build, browser QA, independent review, docs and evidence; commit/push verified main.

## Decisions and evidence
- User chose top 16 league-wide. Fixed bracket, higher-seed home court and Finals MVP from the champion's Finals-only production are the selected implementation defaults.
- Reuse the active checkout and preview; main pushes remain explicitly authorized by the ongoing task.
- Regular season stays model 3; playoffs use an optional independently versioned extension, avoiding unnecessary replay changes or duplication of the regular-season simulator.
- Core tests: nine pass, including independent box reconciliation, deterministic modes, home pattern, stop-at-four, and abort. Integration: 39 targeted state/persistence/App tests pass. UI: 18 targeted tests pass.
- Independent review found one tie-breaking defect: mathematically equal Finals impact could differ by floating-point rounding. Reproduced wrong winner 135 vs expected 65; integer-tenths ranking fixed it (RED → GREEN). No other review findings.
- A full run exposed the existing early Skip reveal race. A dedicated layout-timing regression reproduced 0 visible games instead of 82; retaining the explicit skip for that result fixes it (RED → GREEN). No test timeout or assertion was weakened.
- Browser QA verified saved partial/full progression, 89-game postseason, champion/Finals MVP, both-team boxes, player search/totals, keyboard navigation and no overflow at 1440/390/320. Evidence in handoff and design QA.
- Final verification: 164 tests across 27 files passed; TypeScript/production build and diff whitespace checks passed. No unresolved review findings. Concurrent arcade-design documentation commit was preserved; playoff changes are committed separately.
