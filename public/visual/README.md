# Kanto clubhouse art

Generated raster backgrounds for the selected Kanto Clubhouse design, October 20, 2026.

- `kanto-arena.png`: 1942 × 809 pixel basketball arena. Decorative background; foreground Pokémon use the game’s existing sprite catalog.
- `kanto-town.png`: 1024 × 1536 indigo pixel town for the desktop navigation rail.

Generated with the image generation tool for this project. The backgrounds contain no baked UI or statistics. Existing Pokémon and trainer assets retain their existing project provenance.

The UI display font is Jersey 10 from `@fontsource/jersey-10` (OFL-1.1); body text uses the existing Inter font. Navigation icons come from `pixelarticons` (MIT). Their license files ship in the respective installed packages.

The static trainer gallery shares the Jersey 10 font through `jersey-10-latin.woff2`; `jersey-10-LICENSE.txt` preserves its OFL-1.1 license. All trainer images there use the existing local catalog.
